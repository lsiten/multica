## Security checks

- **Backend identity discovery is owner-gated.** `server/internal/handler/local_review_inventory.go:16-30` first requires runtime workspace access, then matches authenticated daemon identity or the runtime owner. Daemon credentials cannot use a supplied user header to bypass the daemon branch. The routes use `DaemonAuth` (`server/cmd/server/router.go:1435-1437,1468-1469`); PAT/cloud-PAT/JWT authentication overwrites the user identity header. The existing workspace check is in `server/internal/handler/daemon.go:54-81,90-108`.
- **Task/runtime/workspace mismatches fail closed.** The explicit-runtime endpoint loads the task in the authorized runtime workspace and compares its stored runtime (`local_review_binding.go:13-29`). Discovery authorizes the task's stored runtime, verifies the task in its workspace, and returns metadata with `Cache-Control: no-store` (`:34-57`). Desktop checks discovered task/workspace identity before proceeding (`apps/desktop/src/main/local-review-request.ts:19-25`). No request-provided owner or actor is used to grant access.
- **Profile selection stays pinned.** `local-review-request.ts:16-26` resolves once and passes that profile to discovery, health, and review. The callback uses the named profile configuration, encoded task path, and bounded cloud request (`daemon-manager.ts:1412-1426`). `fetchWorktreeManager` uses the supplied profile's port, token, and profile header (`:209-230`), without resolving the newly active profile after health. The health schema and ownership helper require the exact profile and runtime inside the requested workspace (`packages/core/types/local-review.ts:4-8`; `apps/desktop/src/shared/local-review-routing.ts:3-6`).
- **Local mutation has independent daemon enforcement.** `server/internal/daemon/worktree_review.go:126-163` rejects missing/wrong bearer, nonempty Origin, wrong profile, and unregistered runtime/workspace. Mutation requires runtime and command identity, checks task provenance, and replaces the caller actor with `local-runtime:<runtime>` (`:165-182,209-220`). Desktop input parsing strips unrecognized fields, bounds comment/command sizes, and constrains actions (`packages/core/types/local-review.ts:10-21`).
- **Legacy provenance is verified before being persisted.** `server/internal/daemon/local_review_legacy.go:13-24` queries the owner-authenticated backend and compares all three binding identities. Only a missing binding activates fallback; unreadable/malformed bindings fail closed (`worktree_review.go:171-179`). Persistence rejects an existing conflicting binding and propagates read/write errors (`local_review_legacy.go:28-39`). Both normal mutation and merge recovery persist after the environment reservation and cross-process lock (`worktree_review.go:222-250`; `local_review_recovery.go:24-51`). The existing writer uses a same-directory temporary file and rename, checking marshal/write/close/rename errors (`server/internal/daemon/execenv/review_runtime.go:21-38`). No newly introduced arbitrary write target was identified: the environment root is resolved through task/workspace ownership.
